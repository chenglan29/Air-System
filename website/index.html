常见问题

Q: 食用指南？
A:
1.下载 Air System ,建议下载 1.X.X-with-recommended-applications.zip
2.解压后进入 server/
3.若您下载的是 1.X.X-with-recommended-applications.zip 或 1.X.X-with-modules.zip 可以直接在命令行输入 node . 启动
若您下载的是 1.X.X.zip 可以先输入 npm install 进行模块的自动补全再输入 node . 启动
4.您可以在应用商店下载需要的软件，并安装(解压应用至 server/ )
5.用浏览器打开 client/index.html 或者在线客户端
Q: 系统要求是什么？
A: 支持大部分可以装 Node.js-v21.7.3 的系统
